# **Курс по классам**
### Моё руководство по классам

#### Магические методы
\_\_new\_\_ - Вызывается перед созданием класса  
\_\_init\_\_ - Вызывается после new, В нём прописывается присвоение значений переменной класса
\_\_del\_\_ - Вызывается, когда объект удаляется сборщиком мусора, что-то важное лучше не вставлять
\_\_enter\_\_ - Вызывается при входе в блок with
\_\_exit\_\_ - Вызывается при выходе из блока with
